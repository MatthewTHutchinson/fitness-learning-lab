# Dose, progression, and autoregulation

## Dose is multidimensional

| Adaptation | Dose variables that deserve attention |
|---|---|
| Strength | load, hard sets, specificity, rest, effort, frequency |
| Hypertrophy | hard-set volume, range, effort, frequency, recovery |
| Power/speed | intent, output quality, load/contact count, long rest |
| Skill | successful high-quality attempts, feedback, variation, fatigue |
| Mobility | range, active control, load, duration, frequency, next-day response |
| Tendon capacity | loading magnitude, duration, frequency, progression, symptoms |
| Conditioning | intensity domain, duration, intervals, modality, total load |

## Progress one reason at a time

- **Double progression:** add reps inside a range, then add load.
- **Volume progression:** add a set only when quality and recovery support it.
- **Range progression:** gradually work through a larger controlled range.
- **Density progression:** perform comparable quality work in less time; use
  carefully when speed or maximal strength is the goal.
- **Complexity progression:** use for skill, not as a substitute for overload.

## Autoregulation ladder

Use the simplest signal that answers the decision.

1. planned rep range plus clean technique
2. RIR/RPE for effort
3. performance trend across sets
4. readiness and symptom rules
5. velocity measurement when the added precision changes a decision

Autoregulation is not “do whatever feels good.” It is a prewritten rule that
maps an observation to an adjustment.

Example: “Complete 3–4 sets of 5–8 at 2–3 RIR. Add the fourth set only if the
third set remains technically consistent. If warm-up performance is clearly
down, use the same movement for two easier sets instead.”

## When to progress

Progress after repeated evidence that the current dose is tolerable and no
longer sufficiently challenging. Do not progress every variable together. For
quality-sensitive work, stop or regress when output or execution meaningfully
deteriorates even if you could grind out more volume.
